# QuizMaster - System quizów typu Kahoot

Projekt zespołowy na zajęcia z interfejsów graficznych.

## Opis projektu

QuizMaster to aplikacja webowa inspirowana Kahoot, umożliwiająca prowadzenie interaktywnych quizów w trybie asynchronicznym. Prowadzący importuje quiz z pliku JSON, generuje PIN, a uczestnicy dołączają i rozwiązują pytania we własnym tempie.

## Struktura projektu

Projekt realizowany jest zgodnie z metodyką projektowania interfejsów użytkownika w **6 etapach**:

- **Etap 1**: Zarys projektu (problem, użytkownicy, rozwiązanie)
- **Etap 2**: Analiza użytkowników i zadań
- **Etap 3**: Szkice interfejsu + scenariusze
- **Etap 4**: Prototyp papierowy (testowany na użytkownikach)
- **Etap 5**: Prototyp komputerowy (funkcjonalny)
- **Etap 6**: Finalna implementacja + prezentacja

## Technologie

- HTML5, CSS3, vanilla JavaScript
- localStorage API (symulacja backendu)
- Brak frameworków - prosta aplikacja webowa

## Jak uruchomić?

Każdy etap ma swój katalog z dokumentacją. Etapy 5 i 6 zawierają działający kod:

```bash
# Etap 5 lub 6
cd etap-5-prototyp-komputerowy/  # lub etap-6-finalna-implementacja/
# Otwórz index.html w przeglądarce
```
